# Web前端复习刷题站 · 产品设计文档

> 版本：v0.1（MVP）
> 更新日期：2026-08-30
> 状态：MVP 已上线，功能围绕单一题库数据源展开

---

## 1. 产品概述

### 1.1 一句话定位
一个面向 Web 前端（实际为全栈）复习场景的轻量刷题网站，用题库巩固知识点、即时反馈正确率并沉淀错题。

### 1.2 解决的问题
- **知识零散**：复习题量大（358 题）、题型多、章节杂，纸面刷题难回顾。
- **即时反馈缺失**：传统刷题需要翻答案，缺乏即时正误反馈。
- **进度不可追踪**：无法知道哪些题会、哪些题错，重点不突出。

### 1.3 核心价值
让用户以**“筛选 → 作答 → 即时反馈 → 错题强化”**的闭环，高效完成复习。

---

## 2. 目标用户与使用场景

| 用户 | 场景 | 核心诉求 |
|------|------|---------|
| 学生 / 备考者 | 考前复习、章节查漏 | 按章节/题型针对性刷题 |
| 求职者 | 面试准备 | 快速过一遍高频考点 |
| 自学者 | 日常巩固 | 记录进度、复习错题 |

---

## 3. 整体方向

- **纯前端、无后端**：题目数据随代码打包，进度存浏览器本地，零部署成本、即开即用。
- **数据驱动**：题库由 `docx` 解析脚本统一生成结构化 JSON，题库更新只改脚本 + 重跑。
- **闭环增强**：MVP 跑通“刷题—判分—错题”主链路，后续围绕数据纵向深化。

---

## 4. MVP 功能范围

### 4.1 题库数据
- 支持**单选 / 填空 / 判断**三种题型（简答无参考答案，暂不收录）。
- 章节名归一化，跨题型统一（如 `SpringBoot`、`MyBatis 与 Druid`、`Vue3 基础` 等 8 个章节）。
- 解析脚本可重复执行，保证数据更新与可追踪。

### 4.2 刷题
- **题型 + 章节双重筛选**，自由组合进入练习。
- 单题卡片式呈现，支持上一题 / 下一题导航。

### 4.3 即时判分
- 单选 / 判断：点击选项即判对错并高亮正确答案。
- 填空：输入答案后核对，忽略大小写与空白差异。

### 4.4 进度与错题本
- 答题结果持久化到 `localStorage`，刷新不丢失。
- 统计：已答 / 答对 / 答错 / 正确率。
- 错题本自动收集答错题，支持反复重刷，答对后从错题本移除。

## 5. 信息架构（页面）

```
Web前端复习刷题站
├── 首屏
│   ├── 统计条（已答/答对/答错/正确率）
│   └── 筛选区（题型 + 章节 + 错题本 / 重置进度）
└── 题目区
    ├── 进度指示（第 x / 共 n 题，已答状态）
    ├── 题目卡片（题干 + 选项/输入框 + 判分反馈）
    └── 上一题 / 下一题
```

---

## 6. 核心数据结构

```jsonc
{
  "id": 1,              // 唯一标识
  "type": "single",     // single | blank | judge
  "chapter": "SpringBoot",  // 归一化章节
  "question": "题干",      // 题目内容
  "options": ["A", "B"],   // 仅单选有
  "answer": 0              // 单选用下标；填空为字符串；判断为布尔
}
```

- 进度存储：`Record<questionId, boolean>`（false 即错题），存于 `localStorage`。

## 7. 技术方案

| 维度 | 选型 |
|------|------|
| 框架 | Vue 3 + TypeScript + Vite |
| 数据 | 打包 JSON（`src/data/questions.json`） |
| 存储 | localStorage |
| 测试 | Vitest + @vue/test-utils |
| 数据生成 | Node 脚本（jszip 解析 docx） |

## 8. 后续规划（非 MVP）

- 随机 / 乱序练习，避免题序记忆。
- 模拟考试模式：指定章节、限时、交卷出分。
- 正确率 → 薄弱知识点标签，强化推荐。
- 支持简答题（补充参考答案要点）与综合题。
- 题库在线管理 / 多题库切换。

---

## 9. 成功指标

- 作答量：每日活跃作答题目数增长。
- 正确率提升：同一用户错题重复作答正确率趋势上行。
- 留存：错题本使用率、二次访问率。
